# Power and suspend validation

English · [简体中文](./power-validation.md)

This English overview links to the [full Chinese reference](./power-validation.md) for commands and evidence.

This record covers the existing Niri setup. It distinguishes unplugged shutdown, U-Boot charging wait on USB power, and measured suspend/resume. U-Boot charging wait does not establish low-power offline charging. Keep the power source, connection state, suspend mode, and measured interval with each result.
